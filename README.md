# Candles & Scents 

Reviva Atelier is a small **E-Commerce** site focused on **candles**, **diffusers**, and **home sprays**.

> Run frontend

```bash
ng serve
```

> Run Docker

```bash
docker compose up -d
```

---

## Accessibility

- Sign language support;
- Self-Contrast;
- Voice;
- TAB navigation;
- Adaptable text source.
